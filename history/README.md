# Hosted measurement history

This archive contains independently checked GitHub-hosted measurements.
Each directory retains a summary, immutable observation metadata, full task
outcomes, accepted proofs and evidence checksums.

The active campaign uses the NNUE bundled in each measured product commit.
Earlier hosted symbolic measurements and newer NNUE measurements form one
AgdaProver history, as declared by `../participants.json`. Their original
settings and scores remain unchanged. Local measurements are kept privately
and are not part of this public archive.
