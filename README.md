# ProverStrength observations

This data branch contains campaign specifications, GitHub-hosted measurement
evidence and queue receipts. The installable evaluator lives on `main`.

[View the public chart](https://egbertrijke.github.io/ProverStrength/).

The active campaign uses each product commit's bundled NNUE. Earlier hosted
symbolic measurements and newer NNUE measurements appear in one AgdaProver
history. `participants.json` maps campaigns to participating provers; settings
remain in the original records. Local measurements are not published here.
The task bank, protocol and evidence checksums distinguish measurements without
changing their scores.
